This version is a self-contained offline-first web app. It deliberately has NO external JS libraries and no relative app.js file, so opening index.html cannot fail because a sibling script was blocked.

Implemented:
- Reference-inspired welcome/home visual language: pastel lavender/pink/blue/mint, mountain/lake scenery, illustrated book stack, floral accents, script typography, no emoji/text icons for navigation.
- Revision Series with automatic 2-day, 9-day and 30-day scheduling from the date added.
- Mistake Notebook automatically creates the same 2/9/30 revision schedule.
- Test Analysis with four-quadrant analysis, score trend, accuracy, best/average score and test history.
- Formula & Notes: text notes plus offline image upload/storage.
- Daily planner with tick-off and progress percentage.
- Weekly and monthly planner views with working date-based task lists.
- Study-hours timer that records minutes by date.
- Flashcards with front/back flip and know/don't-know tracking.
- Mind map editor with saved central topic and four branches.
- Master Planner with short/monthly/mid/long goals and progress controls.
- Backup/restore of app data.
- Fully local storage and offline operation after first load.

IMPORTANT: Android APK compilation is not included because the current build environment does not contain the Android SDK/build tools. The /android folder is a native WebView project skeleton for later APK compilation. The single-file index.html is the immediately testable build.
